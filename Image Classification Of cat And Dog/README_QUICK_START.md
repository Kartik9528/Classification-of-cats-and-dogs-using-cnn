# 🚀 QUICK START - Cat & Dog CNN Website

## ⚡ Super Quick Start (30 seconds)

### Windows Users:
1. **Double-click** `run_website.bat`
2. Wait for browser to open
3. Upload images and enjoy!

### All Users:
```bash
python launch_website.py
```

## 🆘 Troubleshooting

### "Python not found"
- Install Python from [python.org](https://python.org)
- Make sure to check "Add to PATH"

### "Module not found"
- Run: `pip install flask tensorflow numpy matplotlib pillow`

### "Port in use"
- Close other applications using port 5000
- Or change port in the script
