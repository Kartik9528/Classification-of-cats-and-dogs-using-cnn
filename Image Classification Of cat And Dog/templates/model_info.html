Model Summary
{{ model_summary }}
Architecture Overview
Input Layer: 224×224×3 (RGB Images)
Convolutional Blocks: 4 blocks with increasing filters
Pooling: MaxPooling2D for dimensionality reduction
Regularization: Batch Normalization + Dropout
Dense Layers: 512 → 256 → 2 neurons
Output: Softmax activation for binary classification

Model Features

  • Data Augmentation: Rotation, shifting, flipping, zooming
  • Regularization: Batch normalization and dropout layers
  • Early Stopping: Prevents overfitting during training
  • Learning Rate Reduction: Adaptive learning rate scheduling
  • Model Checkpointing: Saves best model during training
  • Global Average Pooling: Reduces overfitting vs. flatten

Technical Specifications

Dataset Requirements
  • • Image size: 224×224 pixels
  • • Format: JPG, PNG, GIF, BMP, TIFF
  • • Color: RGB (3 channels)
  • • Minimum: 100 images per class
System Requirements
  • • RAM: 4GB minimum, 8GB recommended
  • • GPU: Optional but recommended
  • • Storage: 2GB for model + data
  • • Python: 3.7+ required
Performance
  • • Training: 30-60 minutes
  • • Inference: <100ms per image
  • • Batch size: 16-32 images
  • • Epochs: 30-50 recommended

Usage Instructions

Command Line Usage
# Train the model
python train_model.py

# Predict single image
python predict_image.py image.jpg

# Batch prediction
python predict_image.py --batch folder/
Python API Usage
from cnn_model import CatDogCNN

# Load model

cnn.load_model('model.h5')

# Predict
